# Security Policy

I don't expect much issues on security, as the MMIC Sound Player is designed not to save any information to any servers. 
If you find a vulnerability that is critical to the safe and legal operation of the MMIC Sound Player, heres how to report it.

## Supported Versions

Currently, ALL beta versions of the MMIC Sound Player all the way back to 1.1.8pr1 are supported. That is every released version.
If you supposedly find earlier versions (1.1.8b4 and below) they are not supported or offical and those websites could contain malware.
Do not submit warnings on custom clients, that is the work of that client's developer to fix.

## Reporting a Vulnerability

If you find a security vulnerability, heres what you need to know before submitting a issue

- What component of the Sound Player is not secure (client, MMIC Live server, Index Server, extenstions, etc.)
- Where the code is or what feature it affects

Its also very useful if you can give recommendations on how I'd fix it.
