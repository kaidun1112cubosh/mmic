# Info on the MMIC Launcher
For simplicity, the MMIC Launcher is a small program that's 8MB packaged that is used as a way to access the MMIC Sound Player. Its based off of Scratch Loader GX. Its PMP file is in there if you want to know what it is.
It can download the latest release build of the MMIC Sound Player from here, and you can save the client to your computer from there.
That way, you can upload it to use offline or if you don't like a update I put out there or you computer cannot handle a update.
