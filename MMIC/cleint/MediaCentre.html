MediaCentre

About Mediacentre

MediaCentre is the music engine that powers The MMIC Sound Player

It was introduced after 1.1.8b2 as a improvement to the old player, that was heavy and a RAM hog. MediaCentre fixed that with version 1.0, then 1.0i ("i" for integrated, as its integraded in the MMIC Sound Player's code). 1.1 w/ video came out, with 1.2 w/ and w/o video also coming. The MMIC Sound Player is using 1.2i Audio.

Actions

When you click the play button and select Folder, you have 5 things you can do.

  1. Add files
  2. Delete all files
  3. Play all files
  4. Play all files starting at (index)
  5. Export playlist
  6. Open help

Add files

Name how many files to, and import them one by one, as batch import cannot exist in MediaCentre when integraded.

Delete all files

Delete all uploaded files, to start the playlist over or something.

Play all files

Plays all files from the first to last and loops it

Play all files starting at (index)

Play all files starting at the number you entered. If its too big or small, then MediaCentre may break. Luckily, we now tell you how many files you have imported so this isnt really a problem.

Export playlist

Get all tracks back in a zip. This is kinda unreailable integraded, as you can just use the MMIC Sound Player to export everything.

Look of the player

  • Mode (What mode are you on? Folder [local] Cloud [download and play] or Radio [RTC stream]?)
  • Cover (The album cover, or if you file has none in local mode, that image thats there displays.)
  • Track/Title (Self-explaintory. If no tags on local, its the file name)
  • Artist (The artist, just says unknown if there is no known one on Cloud or no tag for it on Local)
  • Album/Source (The album, sometimes sources are put here. No album tag or meta? Just says unknown)
  • Back (Previous track)
  • Play/Pause (Do I even have to explain this one?)
  • Next (Skip to next, as if it had ended)
  • Media Button (How to access local features, how you get here, and to show the player if you minimized it.)
  • Close player (Exit the player and move on)
  • Minimize player (Hide the player without killing it. You have issues if its hidden and it goes to the next file however)
