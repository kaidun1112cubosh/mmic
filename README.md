# The MMIC Sound Player

## I don't think we need that much of a description. Its self-explanatory, right?

The MMIC Sound Player is a music player created in the graphical programming language of Scratch. As you may already know, Scratch has many mods, most based off of [TurboWarp](https://turbowarp.org/), a simple mod to run Scratch projects faster by running them at higher framerates then Scratch's 30, and by compiling the code to JavaScript, so it's easier for the browser to run. 

The MMIC Sound Player has a whole history on normal Scratch. You can contact me and ask about that if you want. 

Long story short, I could not save The MMIC Sound Player to Scratch's servers as the project got too large. So a year later, I moved its remains elsewhere, and built off what I had leftover. 

Since the version that I discontinued it on was 1.1.7, the new version will be 1.1.8. 

Earlier versions of the MMIC Sound Player were extremely unstable, and could not play music normally. You had to use the backaudio, which in itself is unstable. 

So I invented MediaCentre, a audio engine using [SharkPool's](https://sharkpools-extensions.vercel.app/) [Tune Shark V3](https://sharkpools-extensions.vercel.app/extension-code/Tune-Shark-V3.js) and a handful of other extensions with it, ported it to MMIC and started working.

With MediaCentre, I can effectivity store as many audio file that I want on my computer, and I can also add cloud features to it.

So now, the MMIC Sound Player will be a Cloud based, ad free open-source music player that takes no data relating to you, no money, nothing at all. That is the exact opposite of other music streaming platforms like Spotify, YouTube Music, and Apple Music. They make you pay monthly subscriptions or you deal with annoying ads every day. And I know that if a program you want doesn't seem to exist, you go ahead and make your own.
